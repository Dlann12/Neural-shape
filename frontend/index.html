Arsitektur TripoSR Transformer

1. ViT Tokenizer (DINO-v2)

Mengekstrak visual feature tokens berkulitas tinggi dari input 512×512.

2. Triplane Transformer 1D

Memetakan 2D token ke 3 bidang ortogonal (XY, XZ, YZ) NeRF volumetrik.

3. Continuous NeRF MLP Decoder

Menghitung densitas dan warna RGB kontinu di setiap titik ruang 3D.

4. CPU Marching Cubes

Ekstraksi jaring poligon 3D halus instan dengan warna per vertex.
